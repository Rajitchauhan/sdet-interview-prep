## How to study each session

1.  Pehle lesson ek baar continuously read karo.
2.  Second pass mein key terms highlight karo.
3.  Har concept ko apne words mein bolkar explain karo.
4.  Example ko MindBridge checkout ya apne Playwright project se connect
    karo.
5.  Practice questions bina notes dekhe answer karo.
6.  Jo answer weak ho, us topic ko revise karo.
7.  Lesson checklist tabhi tick karo jab explain kar pao---not just read
    karne ke baad.

## Module 1 final assessment

Notes close karke answer do:

### Section A --- Concepts

1.  QA aur QC ka difference example ke saath explain karo.
2.  UAT ka main objective kya hai?
3.  RACI mein Accountable aur Responsible ka difference kya hai?
4.  Exhaustive testing impossible kyun hai?
5.  Pesticide paradox kya hai?
6.  Absence-of-errors fallacy ka practical example do.

### Section B --- Scenario

MindBridge checkout mein ZIP code field hai. Valid sample `94105` hai.
Lab instructions ke mutabik `testing` accept ho raha hai.

1.  Happy path kya hoga?
2.  At least five edge-case inputs list karo.
3.  Kaunse testing principles yahan apply hote hain?
4.  Expected result kya hona chahiye according to supplied lab?
5.  Bug report mein kaunse sections include karoge?
6.  Agar tumne app run nahi ki, to actual result ko kaise accurately
    represent karoge?
